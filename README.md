# vogue-clothing-shop
Vogue – Fashion E-Commerce Website 💃🛒
Vogue is a stylish and responsive clothing fashion brand website. It features a modern design, product listings, shopping cart features, and a functional backend to manage user and product data.

🔥 Features
Clean and responsive front-end built with HTML, CSS, and JavaScript
Simple shopping cart and product browsing experience
Backend integration using PHP and phpMyAdmin (MySQL)
User data and product information stored in a database
Easy to customize for different fashion or e-commerce ideas

🚀 Getting Started
Prerequisites
To run this project on your local machine:
XAMPP or any web server with Apache, PHP, and MySQL
A browser (Chrome, Firefox, etc.)

Installation
Clone this repository or download the ZIP:
git clone https://github.com/Kashish1090/vogue.git

Move the project folder (vogue) into your htdocs directory inside XAMPP:
/xampp/htdocs/vogue

Start Apache and MySQL from the XAMPP control panel.
Open phpMyAdmin and create a new database, e.g., vogue_db.
Import the SQL file (if provided) into vogue_db to set up the tables:
Go to phpMyAdmin > vogue_db > Import
Choose your .sql file and import

Open your browser and go to:
http://localhost/vogue

🛠️ Technologies Used
Frontend: HTML, CSS, JavaScript
Backend: PHP
Database: MySQL (via phpMyAdmin)
Local Server: XAMPP
